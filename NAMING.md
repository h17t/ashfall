# Naming

The working title is **MOURNWAKE**. This file records how it was chosen and what was and was not checked. None of this is legal advice; before any commercial release, run a real clearance search (USPTO, EUIPO, WIPO, and the relevant national registers in Class 9 and Class 41) and have counsel review the name and the asset list.

## How the search was run

Checks were made on 2026-09-05 from a sandboxed environment. Web search (general index) was available. Direct fetches of the Steam store, itch.io, the USPTO trademark search and TMview were **blocked by the network egress policy**, so store and register checks below are what the general web index shows, not a first-party search. Domain checks are DNS resolution only (an unresolving name is very likely unregistered, but is not a registrar lookup). Social handles were checked by search, not by the platforms' own lookups.

| Channel | Checked | Method |
|---|---|---|
| Steam | indirect | web search restricted to store.steampowered.com results |
| itch.io | indirect | web search |
| Google Play / App Store | indirect | web search |
| USPTO (Class 9 / 41) | **not checked** | tmsearch.uspto.gov blocked |
| EUIPO / TMview | **not checked** | tmdn.org blocked |
| Domains .com / .game / .gg | DNS only | resolution attempted |
| Social handles | indirect | web search |
| General (game, book, film, band) | yes | web search |

## Decision

**MOURNWAKE.** A wake of mourning; waking in mourning; the wake a death leaves behind you. Two syllables, two real words, no invented spelling, and it names what the game is: a funeral that will not end because the guest of honour keeps getting up.

WAKEHOUSE is the fallback if a first-party register search turns up a MOURNWAKE mark.
